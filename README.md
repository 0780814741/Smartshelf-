# SmartShelf

One app for small shops: sell, stock and prices, debts, and a daily profit report.
Data is saved in the browser on the phone (localStorage). No server code.

## Deploy on Render (static site)
1. Upload index.html, render.yaml and README.md to a GitHub repo.
2. Render: New > Static Site > connect the repo. Build command: empty. Publish directory: `.`
3. Open the URL on a phone, then Add to Home Screen.
